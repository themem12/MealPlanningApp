# OrumiApp

OrumiApp MVP Vision
Problema

Las personas que siguen un plan nutricional suelen recibir la información de forma dispersa o poco práctica para consultar durante el día.

Solución

OrumiApp ayuda a consultar de forma simple y rápida un plan nutricional previamente definido y dar seguimiento al cumplimiento de las comidas planificadas.

Usuario principal

Personas que siguen un plan nutricional, normalmente proporcionado por un nutriólogo.

Usuario secundario

Personas que organizan sus comidas por cuenta propia.

Acción principal

Ver qué me toca comer hoy.

Acción secundaria

Marcar comidas como realizadas.

Resultado esperado

Poder revisar posteriormente qué tan bien seguí mi plan nutricional.

Lo que sí es
Meal planner
Consulta rápida del plan
Seguimiento de cumplimiento
Historial de cumplimiento
Lo que no es
Food diary
Calorie tracker
Macro tracker
Base de datos nutricional
Escáner de alimentos
